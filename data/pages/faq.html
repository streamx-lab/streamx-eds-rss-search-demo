Answers to common questions about running and editing this static website locally.

Common questions

Does it need a server?

No. Open index.html directly in a browser.

Does navigation work locally?

Yes. Every page links to the other HTML files using relative paths.

Is search server-side?

No. The header search filters the ten page names entirely in the browser.
